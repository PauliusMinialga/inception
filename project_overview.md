# **Project Overview: Inception**

This project is a system administration exercise focused on using Docker to virtualize a multi-service infrastructure. The primary goal is to deepen your understanding of system administration concepts by building and orchestrating several Docker containers.

You will set up a web application environment consisting of a web server, a content management system, and a database, each running in its own dedicated container. The project requires you to create your own Docker images from scratch, manage container networking, and handle data persistence using Docker volumes.

The entire setup must be deployed on a virtual machine and managed via a Makefile and docker-compose.yml. This project emphasizes best practices for security and configuration, such as using environment variables for sensitive data and restricting network access.
